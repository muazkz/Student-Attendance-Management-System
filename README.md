# Student Attendance Management System (SAMS)
A Student Attendance Management System is a digital solution designed to record, track, and manage student attendance efficiently. The system allows teachers or administrators to mark attendance electronically, reducing paperwork and minimizing human errors. It stores attendance records in a centralized database, making it easy to monitor student participation and generate attendance reports.

The system typically includes features such as student registration, attendance recording, attendance history, report generation, and user authentication. Teachers can quickly mark students as present, absent, or late, while administrators can view attendance statistics and identify students with attendance issues.

By automating the attendance process, the Student Attendance Management System improves accuracy, saves time, enhances record management, and helps schools maintain better communication regarding student attendance. It also supports data-driven decision-making to improve student performance and discipline.

# Key Features and Capabilities of the System
1. Dynamic Class Roster Management: The project features a comprehensive student registration system that allows administrators to add and remove student profiles dynamically. The system enforces data integrity through SQLite constraints, automatically detecting and preventing duplicate Student IDs while maintaining an orderly, sorted master list of all active students.

2. Automated Daily Attendance Tracking: The project provides an automated workspace for managing daily attendance sheets by specific dates. For every new date selected, the system automatically fetches the latest student list from the master roster and applies a default "Present" status, eliminating the need for manual record recreation every single day.

3. Real-time Statistics and Dashboard Tracker: A live statistical summary panel was developed to provide immediate insights into classroom attendance metrics. The dashboard automatically calculates and displays the total class size, the count of present and absent students for the selected day, and computes the exact attendance rate percentage in real time.

4. Flexible Record Management and Persistence: The project enables users to seamlessly update and review attendance data. Users can select any student from the table to toggle their status between "Present" or "Absent" before writing the records securely into the local SQLite database. The system intelligently differentiates between saving brand new records and updating existing past logs without duplicating database rows.
